Master Data Provisioning (The Sequential Write)
The system then iterates through several functions to create and write master files. The order is strict:
1.  **`DownSTGNM`**: Writes `ROUTELST.LST` (List of routes). 
Public Type RouteLST        ' Loaded via ROUTELST.LST
    Code As String * 5
    Name As String * 25
    NoOfStage As Byte
    MinFare As Single
    FareType As Byte
    AllowHalf As Byte
    AllowConc As Byte
    AllowPh  As Byte
    AllowLug As Byte
    AllowAdjust As Byte
    StartFrom  As Byte
    BusType As Byte
    BusTypeName As String * 16
    OptedKM As Single
    AllowPass As Byte 
 End Type

Public Type Route           ' Typically associated with RTE.DAT
    RouteCode As String * 5
    FareType As Byte
    NOS As Byte
    NoOfDupFare As Byte
End Type

2.  **`DownSTGE`**: Writes `STAGE.LST` (Global stage names).
Public Type Stage
    StageName As String * 12
    Distance As Integer
    temp As String * 2       ' Usually used as null padding
End Type

Public Type STAGEDETAILS     ' An alternate version used in newer firmwares
    StageName As String * 12
    Distance As Single
End Type

3.  **`DownLanguage`**: Writes `LANGUAGE.DAT` (UI strings in the local language).
Public Type LANGUAGE_STAG
    RouteCode As String * 5
    LocalLanguageStageName(23) As Byte   ' 24 byte character array for unicode strings
    stagecode As Integer
    temp As Byte
End Type


4.  **`DownRTE`**: Writes `RTE.DAT` (Detailed route definitions).
5.  **`DownCURRENCY`**: Writes `CURRENCY.DAT` (Currency names/symbols).
6.  **`DownCREW`**: Writes `CREW.DAT` (List of conductors/drivers).
Public Type CREWDET
    EmpName As String * 16
    EmpId As String * 8
    EmpType As Byte
    PassWord As String * 7
End Type

7.  **`DownVEHICLE`**: Writes `VEHICLE.DAT` (List of bus numbers).
Public Type VEHICLE
    BUSID As Byte
    Busno As String * 16
    Reserved As String * 15
End Type

8.  **`DownEXPDET`**: Writes `EXPENSEDET.DAT` (List of valid expense types).
Public Type EXPENSEDET       ' Config sent mapping Expense Types to Names
    ucType As String * 5
    expname As String * 16
    Reserved As String * 43
End Type

Public Type EXPENSES         ' Log returned holding exactly how much was spent
    ucScheduleNo As Byte
    ucTripNo As Byte
    EName As String * 16
    Busno As String * 16
    fExpens As Single        ' Expense Amount
    fDiesel As Single        ' Diesel amount/volume
    ucType As Byte
    Hour As Byte
    Minutes As Byte
    Day As Byte
    Month As Byte
    Year As Integer
    RptNo As Long
    Reserved As String * 11
End Type


### 4. Finalization
*   Once finished, if using USB, it sends a `SHUTDOWN`
